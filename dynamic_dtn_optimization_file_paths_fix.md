# Dynamic DTN Optimization File Paths Fix

## Issue Description

The issue was that the functions in `inputlocator.py` (lines 330-803) were returning paths that did not match the actual output directories of `dynamic_dtn_optimization.py`. This caused `dynamic_dtn_optimization_part2.py` to look for files in the wrong locations, resulting in "file not found" errors.

## Root Cause

The root cause of the issue was that the `TempScenarioLocator` class in `dynamic_dtn_optimization.py` didn't override the `get_dynamic_dtn_optimization_thermal_network_folder()` method. This method is used by functions in `inputlocator.py` to get the path to the thermal network folder in the dynamic DTN optimization directory.

When `dynamic_dtn_optimization_part2.py` used the `TempScenarioLocator` instance created by `dynamic_optimizer.get_temp_locator()`, it was using the `TempScenarioLocator` class from `dynamic_dtn_optimization.py`, not the one defined in `dynamic_dtn_optimization_part2.py`. Since the `TempScenarioLocator` class in `dynamic_dtn_optimization.py` didn't override the `get_dynamic_dtn_optimization_thermal_network_folder()` method, it was returning the path to the thermal network folder in the original scenario, not the temporary scenario.

## Solution

The solution was to update the `TempScenarioLocator` class in `dynamic_dtn_optimization.py` to override the `get_dynamic_dtn_optimization_thermal_network_folder()` method, just like the one in `dynamic_dtn_optimization_part2.py`.

We also needed to add the `get_thermal_network_folder()` method to the `TempScenarioLocator` class in `dynamic_dtn_optimization.py`, since the `get_dynamic_dtn_optimization_thermal_network_folder()` method uses it.

### Changes Made

1. Added the `get_thermal_network_folder()` method to the `TempScenarioLocator` class in `dynamic_dtn_optimization.py`:

```python
def get_thermal_network_folder(self):
    """
    Get the path to the thermal network folder in the temp scenario.
    
    Returns:
    --------
    str
        Path to the thermal network folder
    """
    path = os.path.join(self.scenario, 'outputs', 'data', 'thermal-network')
    
    if not os.path.exists(path):
        log().error(f"Thermal network folder not found in temp scenario: {path}")
        raise FileNotFoundError(f"Thermal network folder not found in temp scenario: {path}")
    
    return path
```

2. Added the `get_dynamic_dtn_optimization_thermal_network_folder()` method to the `TempScenarioLocator` class in `dynamic_dtn_optimization.py`:

```python
def get_dynamic_dtn_optimization_thermal_network_folder(self):
    """
    Override to return the path to the thermal network folder in the temp scenario.
    
    This override ensures that dynamic DTN-specific methods look for files in the correct
    location within the temporary scenario.
    
    Returns:
    --------
    str
        Path to the thermal network folder in the temp scenario
    """
    # Return the same path as get_thermal_network_folder()
    return self.get_thermal_network_folder()
```

## Expected Behavior

With these changes, when `dynamic_dtn_optimization_part2.py` uses the `TempScenarioLocator` instance created by `dynamic_optimizer.get_temp_locator()`, it will correctly redirect file requests to the temporary scenario. Specifically:

1. When `get_dynamic_dtn_network_layout_costs_file()` or any other method that uses `get_dynamic_dtn_optimization_thermal_network_folder()` is called, it will look for files in the `<temp_scenario>/outputs/data/thermal-network/` directory, not the `<scenario>/outputs/data/optimization/dynamic_dtn_optimization/thermal_network/` directory.

2. This ensures that `dynamic_dtn_optimization_part2.py` can find the thermal network files generated by `dynamic_dtn_optimization.py` in the temporary scenario.

## Testing

To test the changes, run `dynamic_dtn_optimization_part2.py` and verify that it can find all the files it needs:

```
python -m cea.optimization_new.dynamic_dtn_optimization_part2 --scenario <path_to_scenario>
```

The script should run without any "file not found" errors related to the thermal network files.

## Conclusion

The issue was caused by the `TempScenarioLocator` class in `dynamic_dtn_optimization.py` not overriding the `get_dynamic_dtn_optimization_thermal_network_folder()` method. By adding this method and the `get_thermal_network_folder()` method to the class, we ensure that `dynamic_dtn_optimization_part2.py` can correctly access the thermal network files in the temporary scenario.
