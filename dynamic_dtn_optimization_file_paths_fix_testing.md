## Troubleshooting

If you encounter any errors during testing, check the following:

1. **File not found errors**: If you see errors like "File not found" or "No such file or directory", check the file path in the error message and compare it with the actual file path in the temporary scenario. Make sure the file names match exactly, including any suffixes or units.

2. **Incorrect file content**: If the script runs but produces incorrect results, check the content of the files being read. Make sure the files contain the expected data in the expected format.

3. **Temporary scenario not created**: If the temporary scenario is not created correctly, run `dynamic_dtn_optimization.py` again to recreate it. Make sure the script completes successfully before running `dynamic_dtn_optimization_part2.py`.

4. **Incorrect file paths**: If the file paths are still incorrect, check the functions in `dynamic_dtn_optimization.py` again and make sure they return the correct paths. You can add debug print statements to print the file paths being used.
